# 模糊测试工具性能分析报告

## 1. 实验概述

本实验使用了三种模糊测试工具（AFL、AFLFast和MAflood）对三个不同的目标程序（LAVA-M、ffjpeg和libpng）进行了测试。测试采用了多实例的形式，以评估不同工具在不同场景下的性能表现。

### 测试目标

1. **LAVA-M**：一个基准测试项目，用于评估模糊测试工具的基本性能
2. **ffjpeg**：一个JPEG图像处理库，测试工具对图像处理的能力
3. **libpng**：一个PNG图像处理库，测试工具对复杂格式的处理能力

### 测试工具

1. **AFL**：经典的模糊测试工具，使用遗传算法生成测试用例
2. **AFLFast**：AFL的改进版本，优化了能量调度策略
3. **MAflood**：基于AFL的扩展，增加了多种变异策略

## 2. 实验结果分析

### 2.1 LAVA-M 项目

LAVA-M项目测试结果显示：

- **执行次数**：AFL 1实例执行次数最高，达到72.3百万次，随着实例数增加，执行次数减少
- **执行速度**：AFL 1实例执行速度最快，达到2462.27次/秒，AFLFast次之
- **路径数**：AFL 1实例发现的路径数最多，为394条

### 2.2 ffjpeg 项目

ffjpeg项目测试结果显示：

- **执行次数**：在BMP格式测试中，MAflood执行次数（28.4百万次）高于AFL（21.4百万次）；在JPEG格式测试中，AFL执行次数（46.7百万次）高于MAflood（20.3百万次）
- **崩溃数**：AFL在JPEG格式测试中发现了89个崩溃，远高于MAflood的61个
- **路径数**：MAflood在JPEG格式测试中发现的路径数（555条）略高于AFL（533条）

### 2.3 libpng 项目

libpng项目测试结果显示：

- **执行次数**：AFLFast执行次数最高，达到42.4百万次，AFL次之，MAflood最少
- **覆盖率**：AFL覆盖率最高，达到8.55%，AFLFast次之，MAflood最低
- **崩溃数**：AFLFast发现的崩溃数最多，为27个，AFL次之，MAflood未发现崩溃

## 3. 工具性能比较

### 3.1 执行效率

- **AFL**：在单实例模式下执行效率最高，但随着实例数增加，执行效率下降
- **AFLFast**：执行效率较高，特别是在libpng项目中表现优异
- **MAflood**：执行效率适中，在某些场景下（如ffjpeg BMP测试）表现较好

### 3.2 代码覆盖率

- **AFL**：在libpng项目中覆盖率最高，达到8.55%
- **AFLFast**：覆盖率次之，在libpng项目中为5.23%
- **MAflood**：覆盖率相对较低，需要进一步优化

### 3.3 崩溃发现能力

- **AFL**：在ffjpeg JPEG测试中发现了89个崩溃，表现优异
- **AFLFast**：在libpng项目中发现了27个崩溃，表现最好
- **MAflood**：崩溃发现能力相对较弱，需要改进

## 4. 结论与建议

### 4.1 结论

1. **AFL**：在单实例模式下表现最好，执行效率和路径发现能力强
2. **AFLFast**：在多实例模式下表现较好，特别是在复杂项目（如libpng）中
3. **MAflood**：在某些特定场景下（如ffjpeg BMP测试）有一定优势，但整体表现需要改进

### 4.2 建议

1. **针对不同目标选择合适的工具**：对于简单目标（如LAVA-M），AFL单实例效果最好；对于复杂目标（如libpng），AFLFast可能更适合
2. **优化多实例配置**：多实例模式下，需要合理配置实例数量，避免资源竞争导致性能下降
3. **改进MAflood**：MAflood在崩溃发现和覆盖率方面需要进一步优化，特别是在复杂项目中
4. **结合使用**：可以考虑结合使用不同的模糊测试工具，以充分发挥各自的优势
